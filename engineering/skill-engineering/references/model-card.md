# Model Card

Use this design record only when a skill depends on a model-specific capability,
limit, cost, data boundary, or fallback.

- **MODEL:** <provider, deployment, and version>
- **JOB:** <capability this model must provide>
- **CONTEXT:** <input size, retained context, and tool access>
- **LIMITS:** <known reasoning, latency, language, or modality limits>
- **DATA:** <classification, residency, and retention constraints>
- **COST:** <token/runtime budget and rate limit>
- **EVALUATION:** <representative prompts and acceptance measure>
- **FALLBACK:** <human, deterministic tool, or alternative model>
